MODULE 01 — WILDERNESS GEAR

旷野极限装备干货 登山 / 滑雪 / 徒步.

LAYERS · PACKS · BOOTS · BOARDS · SLEEP SYSTEM

PART A — CLIMBING

登山装备

MOUNTAINEERING
  • 三层穿衣法则：排汗层（速干不选棉）→ 保暖层（抓绒/棉服/羽绒）→ 防护硬壳（防水防风），按行进强度增减
  • 背包容量：单日 25–35L，多日露营 50–65L，高海拔远征 70–85L 外挂更关键
  • 登山靴三看：鞋楦宽窄要合脚、防水膜认准可靠标识、鞋底硬度 B/C/D 随路线技术等级提高
  • 冰爪与头盔：冰爪捆扎/卡式对应靴型，头盔必须通过登山认证，受过撞击即更换
PART B — SNOWBOARD

滑雪装备

SNOWBOARD
  • 板长板型：板长到下巴–鼻梁之间按体重选，新手选全能Camber/Rocker混合板，野雪选长而宽的定向板
  • 雪鞋硬度：软（1–4）容错好学，中等（5–7）进阶自由式，硬（8–10）刻滑与高速稳定
  • 雪服参数：防水静水压 10000mm 起、透湿 10000g/m²/24h 起，高海拔野雪建议 20000+ 双指标
PART C — HIKING

徒步装备

TREKKING
  • 背包背负系统：腰带承担 60–70% 重量到胯骨，背板长度匹配躯干长，肩带只负责稳定不负责承重
  • 睡袋温标：看极限温标之外的"舒适温标"，按营地最低温再留 5°C 余量，湿冷环境优先化纤棉
  • 帐篷：看抗风等级与防水帐底，高海拔用四季帐，公园徒步三季帐即可，重量按预算分配

MODULE 02 — STREET SKATE GEAR

街头滑板装备干货 板面 / 轮子 / 轴承 / 护具.

DECK · WHEELS · BEARINGS · PROTECTION

新手看完不踩坑

一套滑板，先看这五件事

板面材质与尺寸：七层加拿大枫木是主流，脚宽对应板宽——脚 40 码以下选 7.75–8.0，40–43 码选 8.0–8.25，大脚选 8.25+；新手直接买成品整板最省心。

轮子与轴承：街式动作选 99A–104A 硬轮、51–54mm；刷街选 78–87A 软轮、56–60mm。轴承 ABEC-7 钢轴足够日常，重点看防尘密封。

护具全套：头盔 + 护膝 + 护肘 + 护腕四件起步，碗池与速降建议加护臀、穿护甲。

场景搭配：街式选低桥硬轮小板、翻毛皮鞋；碗池泵道选中高桥大软轮与陆冲，抓地优先。

MODULE 04 — CARE & MAINTENANCE

装备维护保养专栏 保养到位，多陪你三季.

CARE — 清洁 / 修复 / 干燥 / 收纳

01

高山硬壳清洗保养

温水 + 中性/功能面料专用洗剂，不拧搅、不暴晒；洗后低温烘干激活防泼水层，普通柔顺剂会堵死透气微孔，严禁使用。

02

滑雪服防水修复

表面不再"挂珠"时，清洗后喷涂/浸洗 DWR 防泼水剂，再低温熨烫或烘干激活；拉链处重点补涂，压胶条开胶及时送修。

03

滑板板面保养

板面绝对避水，受潮会失去弹性；定期检查桥钉松紧、轴承补油、砂纸积砂用硬刷清理，轮面磨偏及时换位或更换。

04

篮球鞋延长寿命

室内外鞋分开穿，外场鞋少打木地板、内场鞋不下水泥；赛后鞋垫取出阴干，别暴晒别机洗，中底缓震有寿命周期，变硬就换。

MODULE 05 — COMMON PITFALLS

避坑专区 这些钱，真的不必花.

DON'T — 户外装备选购常见误区

✕

误区一：盲目追求最高参数

40000mm 静水压硬壳穿去城市徒步，又闷又硬；顶级碳板球鞋在塑胶地一个月磨平——参数过剩 = 花钱买罪受。先确定场景，再匹配指标。

正解：按「最常去的场景」选型，留出一档余量即可。
✕

误区二：网红装备一定适合你

别人的神鞋可能不匹配你的脚型、体重与打法；博主的轻量化清单建立在他们的体能之上。从众下单前，先问自己的身体条件。

正解：参考思路，不照抄清单；尺码与足型优先于品牌热度。
✕

误区三：极限装备只看颜值

配色再好看，头盔没有认证、安全带是杂牌、护具软塌海绵，遇到冲击就是零保护。承力与防护件上的省钱，是最贵的省钱。

正解：防护件先看认证等级与结构，颜值放在最后一票。
