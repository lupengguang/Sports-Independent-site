MODULE 01 — WILDERNESS GEAR · 旷野极限装备干货

登山 / 滑雪 / 徒步：三件最容易买错的事.

LAYERING / PACK & BOOTS / SNOW GEAR

GEAR-W-01 · 登山穿搭

三层穿衣系统完整逻辑

排汗层贴身选美利奴羊毛或聚酯纤维，拒绝纯棉；保暖层抓绒/棉服负责静止保暖；防护硬壳只在风雪雨时穿。三层按需增减，靠"拉链通风"而不是硬扛。

选购高山装备 →
GEAR-W-02 · 登山背包

背包容量怎么选

单日徒步 25–35L；过夜 40–55L；多日重装 / 雪山 60–80L。比容量更重要的是背负系统——腰带要能把 70% 重量传导到胯骨，试装后看腰带是否贴合不顶胯。

徒步背包清单 →
GEAR-W-03 · 登山靴

鞋楦 / 防水膜 / 硬度怎么看

鞋楦决定宽窄，下午试穿留一指余量；防水膜认准 Gore-Tex；硬度B1–B3 逐级对应普通徒步到冰爪雪山。重装走碎石选中高帮 + Vibram 大底。

登山靴与冰爪 →
GEAR-W-04 · 滑雪板

单板板长、板型选择

新手板长到下巴到鼻尖，进阶大山选身高附近；Camber弹性能跳，Rocker容错浮力好，混合板型最通用。先定滑法再看板型，别让涂装替你做决定。

单板滑雪系列 →
GEAR-W-05 · 雪鞋雪服

雪鞋硬度与雪服参数

雪鞋硬度 1–3 新手、4–7 进阶、8–10 公园刻滑，过硬的鞋给新手只会更累。雪服看静水压（≥10000mm）与透湿量（≥8000g/m²/24h），缝线压胶同样关键。

雪鞋雪服选购 →
GEAR-W-06 · 徒步系统

背负 / 帐篷 / 睡袋温标

重装包先调腰带再调肩带；睡袋温标看极限温标 ≠ 舒适温标，按夜间最低温再留 5℃ 余量；帐篷按季节数选，三季帐兼顾重量与抗风，地布延长寿命。

MODULE 02 — STREET GEAR · 街头滑板装备干货

滑板新手：第一套装备别踩这些坑.

DECK / WHEELS / BEARINGS / PROTECTION

GEAR-S-01 · 板面

材质与尺寸选择

首选七层加拿大枫木双翘整板；街式男生常见 8.0–8.25 英寸，女生/脚小选 7.75–8.0。刷街巡航可选陆冲，平花舞板选长板，玩法决定板型而非颜值。

全部板面 →
GEAR-S-02 · 硬件

轮子硬度与轴承

街式动作选 99A–104A 硬轮 52–54mm；刷街选 78–87A 软轮 60mm 左右。轴承日常 ABEC-7 钢轴足够，防尘盖比精度等级更重要，T 型工具随车带。

GEAR-S-03 · 护具搭配

不同场景的护具方案

新手街式：头盔 + 护膝 + 护腕起步三件套；碗池/泵道加护肘；陆冲高速加滑块手套。护具要试戴到"紧而不麻"，摔过一次的头盔直接退役。

MODULE 03 — COURT GEAR · 赛场竞技装备干货

四项赛场运动：一句话讲清选型关键.

BASKETBALL / FENCING / FOOTBALL / BADMINTON

GEAR-C-01 · 篮球

按位置选鞋完整干货

后卫低帮抓地轻量、启动第一；锋线中帮均衡、缓震+侧向支撑两头要；中锋高帮抗冲击、足弓加厚。球衣选透气网眼、版型预留护具空间。

后卫选鞋 →锋线 →中锋 →
GEAR-C-02 · 击剑

剑服 / 面罩 / 剑条选型

训练服 350N、参赛 800N；面罩认准 1600N 与 bib 护颈。新手花剑整剑起步，剑条按剑种区分，电剑另配手线与金属衣，护板穿最内层不能省。

击剑装备 →
GEAR-C-03 · 足球

FG / AG / TF 大底区分

FG 仅天然草，钉长抓深；AG 中高人草，启动与膝盖压力平衡；TF 碎钉通吃人草/硬地，国内野球主力。硬地穿 FG 伤膝断钉，场地定大底。

足球战靴 →
GEAR-C-04 · 羽毛球

拍线磅数与球拍重量

新手男 22–24 磅、女 20–22 磅，磅数越高控制好但越伤手腕；重量选 4U（80–84g）全能，力量型再上 3U。进攻拍头重、控球拍头轻，双打压平抽选速度型。

MODULE 04 — MAINTENANCE · 装备维护保养专栏

保养做到位，寿命多一倍.

四类高频装备保养

  • 高山硬壳外套：温水中性洗剂机洗轻柔档，定期补 DWR 防泼水剂，烘干激活涂层，避免柔顺剂。
  • 滑雪服防水修复：清洗后喷涂/水洗型防泼水剂，中温熨烫或烘干恢复荷叶效应，压胶条开胶及时送修。
  • 滑板板面：避水防砂，受潮会失去弹性；定期紧桥钉、翻面砂纸、轴承上油，轮子偏磨及时换位。
  • 篮球鞋养护：打完抽鞋垫通风、阴干忌暴晒；外场鞋定期清理纹路石粒，气垫鼓包立即停穿。
MODULE 05 — PITFALLS · 避坑专区

钱要花在场景上，不是参数上.

选购四大误区

  • 盲目追最高参数：8000mm 防水足够的雨披场景买 28000mm，多花的钱不会让你更舒适——按最常遇到的天气选。
  • 网红装备≠适合你：大神同款可能是为高水平/特定体型设计的，新手用顶级碳板鞋反而控制不住。
  • 只看颜值下单：纯白色滑板鞋打外场、涂层花里胡哨的板面泡水鼓包，外观是装备最不重要的参数。
  • 护具上省预算：头盔、护板、承力主锁拒绝杂牌二手，受过冲击的护具哪怕没裂也必须更换。
